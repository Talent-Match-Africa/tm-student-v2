# Student Application Submission

Opportunity details provide a three-step application workflow: fit review,
student narrative, and documents/confirmation. Job submissions support cover
letter, experience summary, primary document, and cover-letter document.
Internships support cover letter and one primary document.

The browser validates supported PDF, DOC, and DOCX files up to 10 MB, prevents
duplicate clicks, preserves recoverable errors, and warns before discarding a
draft. A same-origin handler allowlists fields, bounds the request envelope,
refreshes the secure session once, and forwards multipart data without exposing
tokens. The API remains authoritative for MIME signatures, audience, open
dates, ownership, rate limiting, and duplicate races.

The newest profile CV is selected by default. Submissions may instead include a
new local document. Saved-document submissions send only an opaque document id;
the API verifies student ownership and copies the private asset into independent
application storage before creating the application.
